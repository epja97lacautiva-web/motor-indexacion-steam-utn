## 📌 Descripción del Proyecto
Este repositorio contiene la documentación técnica y el modelado conceptual para el desarrollo de un **Motor de Indexación Nativa de Metadatos** integrado al Mercado de la Comunidad de Steam. 

El sistema permite consultar, filtrar y ordenar activos digitales por parámetros avanzados (Float Value, Pattern ID y disponibilidad de pegatinas) directamente desde la plataforma, optimizando la velocidad de consulta mediante el uso de caché local en Redis y desacoplando el tráfico de los servidores de inventario.

---

## 🛠️ Alcance del Trabajo Práctico Integrador
1. **Diagnóstico Sistémico (TGS):** Análisis de Valve Corporation como sistema abierto (entradas, procesos, salidas y retroalimentación).
2. **Planeación Estratégica:** Matriz FODA, definición de metas cuantitativas y cronograma temporal mediante Diagrama de Gantt.
3. **Estructura Organizacional:** Análisis comparativo del modelo tradicional frente a la estructura plana (adhocrática/células) de Valve y definición del Diccionario de Datos inicial.
4. **Modelado de Procesos:** Diagrama BPMN 2.0 (Pools: Cliente y Valve; Lanes: UI, Backend, Inventarios y Pasarela de Pagos) y especificación formal de Casos de Uso (CU-01 y CU-02).
